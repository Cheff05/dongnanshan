# 记忆更新规则

> 本文件是「东南山」记忆系统的行为协议，AI 每次对话结束必须执行。

## 一、什么时候判断

- **每轮对话结束后**自动判断一次（轻量提炼）。
- 主人显式说「记住 X」→ 立即写入；说「忘掉 X」→ 立即删除对应条目。
- 每新增约 5 条记忆，或每周一次 → 提炼更新 summary.md。

## 二、判断标准

### 值得记（有长期价值）

| 类别 | 例子 |
|---|---|
| 基本资料 | 身份、职业、城市、家庭、教育等长期事实 |
| 稳定偏好 | 表达习惯、喜欢/讨厌、交流方式 |
| 观点与理念 | 立场、原则、价值观 —— **主人特别要求，优先级高** |
| 重大经历 | 他认为重要的事：背景、过程、他的感受与看法 —— **优先级高** |
| 项目记录 | 进行中的事、计划、目标与进展 |
| 显式指令 | 他说「记住」的任何内容 |

### 不值得记（短期噪音）

- 临时情绪、一次性抱怨
- 日常琐事、临时安排
- 时点性新闻本身（除非暴露了他的观点立场）
- 他说「不用记」的内容

## 三、条目格式（写入 memory.md）

```markdown
## [YYYY-MM-DD] 类型：观点 | 重要度：高
一句话到几句话，具体、可检索，保留他的原意。
```

**类型取值**：资料 / 偏好 / 观点 / 经历 / 项目 / 目标 / 习惯 / 其他
**重要度**：高 / 中 / 低

## 四、写入纪律

1. 追加不覆盖，旧条目永远保留。
2. 每次写入后告知主人，给他纠正机会。
3. 不确定的宁可不写，或标为低重要度。
4. profile.md 只放静态事实；动态条目一律进 memory.md；提炼结论进 summary.md。
5. 观点类条目：如果他日后改变立场，新增一条「观点变化」条目记录转变，不删旧条。

## 五、摘要提炼（summary.md）

- 时机：每新增约 5 条，或每周一次。
- 内容：从 memory.md 提炼出最能代表主人的核心画像——他是谁、在乎什么、在做什么、观点主线。
- 长度：一屏以内，一眼看懂。
