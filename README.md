# 东南山（枢衡殿）

> **脱敏开源代码版**。本仓库仅含项目结构与可公开源码，用于存档与展示（「赛博纪念碑」）。
> 已移除：所有 API 密钥、CloudBase 环境标识、个人身份信息、本地记忆与对话数据。
> 部署前请在 `.env` 中配置 `TOKENHUB_API_KEY` / `DEEPSEEK_API_KEY`（参考 `.env.example`）。

主人的个人长期 AI 助手。核心是本地 Markdown 记忆体系——可查看、可修改、可迁移，文件即真相。另有可选手机端（cloud/），部署后可随时用手机对话。

## 目录地图

| 路径 | 作用 | 谁看 |
|---|---|---|
| memory/profile.md | 基本资料、偏好、目标（静态为主） | AI 必读 |
| memory/memory.md | 动态记忆条目（按日期追加，带类型标签） | AI 必读 |
| memory/summary.md | 总体摘要（AI 定期提炼） | AI 必读 |
| chats/ | 对话原始记录（按日期归档，只追加） | 参考 |
| prompts/system_prompt.md | AI 人格、立场、记忆协议设定 | AI 必读 |
| prompts/memory_rules.md | 记忆判断标准、条目格式、更新时机 | AI 必读 |
| cloud/ | 手机端云端版（CloudBase）：云函数 + 网页 + 部署文档 | 可选 |

## 运作方式

1. 每次会话开始，AI 读取 memory/ 三个文件，带着主人的背景、观点、经历进入对话。
2. 对话中主动调用记忆：相关时引用他的观点、经历、目标，不重复问已知信息。
3. 对话结束，AI 按 prompts/memory_rules.md 判断本轮是否有值得保存的信息，写入时明确告知。
4. 主人随时可以打开任何文件查看、修改、删除——他改文件就是改记忆。

## 约定

- **换模型**：把 prompts/ 两个文件交给新模型即可，记忆无缝迁移，代码零依赖。
- **隐私**：本地版数据全在本机；手机端需放腾讯云（CloudBase），可定期备份回本地。
- **优先级**：主人的明确期待（注意其观点理念、重视其重大经历）高于一切规则。

## 手机端（可选）

白天电脑用本地版；晚上手机高频场景部署云端版（cloud/）。部署步骤见 `cloud/README.md`。注意：本地与云端是两份记忆文件，建议每周双向同步一次，保持单一真相。
